# Security Policy

Compliance Lab is a local research prototype.  It does not implement production identity, authorization, audit immutability, containment, or compliance-assessment controls.  Please read the security boundaries in the README before using the code.

## Supported versions

Security fixes are applied only to the current default branch.  The project does not publish supported release branches or production packages.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository.  Do not include credentials, personal data, client data, controlled information, or exploit data from systems you do not own or have permission to test.

If private vulnerability reporting is unavailable, do not open a public issue containing sensitive details.  Open a minimal issue asking the maintainer to enable a private reporting channel.

## Appropriate testing

Test only with synthetic data and systems you own or are explicitly authorized to assess.  The repository's demonstration containment action is simulated and must remain non-destructive.
